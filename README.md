# SHADOWZ HUB

A central directory for every website in the SHADOWZ network — with
public browsing, user accounts, and a full 5-tier admin dashboard.

**Start here:** [`SETUP.md`](./SETUP.md) — one-time steps to connect
your own Supabase project and go live.

## Stack

- React + Vite + TypeScript
- Tailwind CSS (black / dark purple / neon purple / violet theme)
- Supabase (Postgres database, Auth, Storage)
- GitHub Pages + GitHub Actions (auto build & deploy on every push)

## Local development

```bash
npm install
npm run dev
```

See `SETUP.md` for the Supabase project setup these commands depend on.
